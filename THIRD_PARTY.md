# Third-party material in this archive

This archive accompanies an anonymous submission. It contains the code for the
experiments reported in the paper (`code/`) and, under `logitscope/`, a modified
snapshot of a third-party inspection tool used for the mechanistic probe in
Appendix D.

## logitscope (bundled under `logitscope/`)

- **Upstream project:** logitscope — "an oscilloscope for transformers" —
  <https://github.com/SiddharthaG09/logitscope>
- **Upstream author:** Siddhartha Guntupalli (GitHub: `SiddharthaG09`)
- **Snapshot used:** the upstream revision as downloaded on 2026-06-24. Files we
  did not touch retain that snapshot's timestamps.
- **License:** the upstream repository declares **no license** (checked
  2026-10-12; the GitHub API reports `license: null` for it). We therefore claim
  no ownership over the upstream code. We include the snapshot only so that the
  probe reported in Appendix D can be inspected and re-run, and we include all
  upstream files unmodified except for the files listed below. The bundled
  `logitscope/README.md` is the upstream author's document, extended by us as
  noted below.

### Reproducing the reported statistics

The quantities plotted in the panel are defined in the paper itself: the mean
per-row total-variation distance between the two prompts' key distributions
(the changed-target share), the count of rows with total-variation distance at
least 0.02 (re-drawn rows), and the split of the displaced mass between the
edit's own columns and positions the edit never touched. They can therefore be
reimplemented from the paper without this bundle.
